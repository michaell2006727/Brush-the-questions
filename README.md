## 项目介绍

Brush-the-questions 是基于 [Exameow](https://github.com/heshengtao/exameow) 规划的个人刷题应用。目标是将已有的 PDF、Word、Excel 题目资料整理成可管理、可练习、可追溯的个人题库，减少手工录题和不同设备之间反复搬资料的工作。

首版交付可安装的 **Android APK**，以 iQOO 手机进行后续真机验证。界面随安装包交付，题库、答题记录、错题与收藏统一保存在个人服务器；iOS 支持安排在后续阶段。

**产品始终保留文档原题和原答案。** AI 用于提取已有题目与解释已确认的参考答案；缺答案保持空缺，经人工补录和确认后才能参与判分。

## 计划提供的能力

以下均为产品规划，**当前尚未实现**。完整规则和验收条件见 [PRD](PRD.md)。

| 能力 | 计划体验 |
|---|---|
| 文档导入 | 支持 PDF、DOCX、XLSX；扫描 PDF 经 OCR 后进入预览 |
| 原题校对 | 对照原件核对题干、选项、答案、章节与图片，标记遗漏、歧义和疑似重复 |
| 题库管理 | 题库命名、章节分类、搜索、编辑、确认删除与导入导出 |
| 日常练习 | 顺序、随机、章节、背题和收藏练习，提供答题卡与逐题保存 |
| 错题复习 | 自动收录错题、重练、人工移出，默认连续答对三次后移出 |
| 限时模考 | 按已确认题目组卷，服务端记录截止时间，交卷后查看结果 |
| AI 讲解 | 用户主动点击生成，独立标注和保存，保留原解析及人工修订 |
| 服务器同步 | 同一账号在不同客户端恢复已保存的进度、错题和收藏 |

计划使用流程：

```mermaid
flowchart LR
    A[上传题目文档] --> B[解析 / OCR / 原题提取]
    B --> C[人工校对与来源核验]
    C --> D[确认入库]
    D --> E[练习 / 错题复习 / 模考]
    E --> F[按需 AI 讲解]
```

## 原题与数据规则

- **答案有来源。** 保留原文件和题目、答案的定位信息；集中答案匹配不确定时提示校对。
- **缺答案不猜测。** 缺少有效参考答案的题标为“待补充”，可背题，不自动判分或调用标准答案型讲解。
- **人工修改受保护。** AI 返回和导入重试不能覆盖已确认题库或人工修订。
- **讲解单独保存。** 原答案、原解析、人工参考答案和 AI 讲解分别管理。
- **服务器保存进度。** 手机只在收到服务器确认后显示已保存；完整离线答题与离线合并不属于首版范围。
- **资料保持私有。** 后端计划统一保护登录、文件和 AI 接口；API Key 由服务器保存和使用。

### 为什么 GitHub 显示 PowerShell？

GitHub 的 Languages 栏根据仓库中已提交的代码文件统计。目前主要代码是 `scripts/` 中的 `.ps1` 环境脚本，Vue、TypeScript 和 Rust 业务源码尚未引入，因此当前统计显示 PowerShell。

这反映的是仓库当前内容；项目的应用与后端选型见上表。业务源码推送并合并到默认分支后，统计会随实际代码更新。统计机制参见 [GitHub 官方说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-repository-languages)。

## 环境使用

按 [Android 环境文档](docs/android-environment.md) 安装并定位外部工具、准备本机配置后，在项目根目录打开 PowerShell：

```powershell
# 激活当前终端的项目环境
. ./scripts/enter-env.ps1

# 检查工具与符号链接权限
./scripts/check-env.ps1

# 验证原生编译与最小 APK 打包
./scripts/smoke-env.ps1
./scripts/smoke-tauri.ps1
```

克隆仓库不会自动安装 SDK、NDK、JDK 或 MSVC。具体版本、目录、配置示例和真机连接方法以环境文档为准。
